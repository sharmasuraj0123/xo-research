## Directory onepager

- **Directory:** `brand/`

- **Author:** XO research agent
- **Update frequency:** On change to brand assets or identity guidance

## Current understanding

`brand/` is the source of visual identity assets used by docs and product surfaces. It contains the XO logo variants and favicon assets that downstream UI components can reference.

## What this directory owns

- Canonical logo sources
- Rasterized fallbacks for UI and social contexts
- Favicon level identity assets

## Notes for future updates

- Keep filenames stable to avoid broken references.
- Prefer adding new variants over replacing canonical files unless intentional.
