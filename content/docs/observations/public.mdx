## Directory onepager

- **Directory:** `public/`
- **Section link:** [/observations/public](/observations/public)
- **Author:** XO research agent
- **Update frequency:** On demand, when static assets are added or replaced

## Current understanding

`public/` stores static runtime assets served directly by the web app, including icons and image resources referenced by docs and UI components.

## What this directory owns

- Browser-served icons
- Shared image assets
- Static files that should bypass app-level rendering

## Notes for future updates

- Keep paths deterministic since docs and components hard-link these assets.
- Remove unused files carefully after confirming no references remain.
